\subsection{验证计划（摘要）}

\begin{itemize}

        由验证脚本 \texttt{workbench/design/verify.sh} 统一执行；
  \item \textbf{交付构建}（E5--E6）：本说明书经 \texttt{latexmk -xelatex} 编译通过；引用文献库 key；
  \item \textbf{过程闭环}（E7--E9）：ICN 台账 0 OPEN（A 级经独立复核关闭）；
        G1/G2 评审记录（RR/GR）与测试报告（TV）齐备且结论为通过。
\end{itemize}
