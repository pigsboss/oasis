# 设计开发 · 阅读清单

> 版本 v0.1（2026-10-10）。引用一律使用文献 key（见 [../registry.md](../registry.md) 与 `../bib/`）。

## 格式与标准（设计必备）

- `duvert2017oifits` — OIFITS 2 标准：观测层接口（OI_VIS2 / OI_T3 等表结构）的设计依据
- `fits_standard40` — FITS 4.0 官方标准：HDU/头部关键字/数据表示的约束（manual 条目）
- `pence2010fits` — FITS 3.0 期刊版（closed，仅元数据备查）
- `greisen2002wcs` — FITS WCS 论文 I：图像/光谱 WCS 构造依据

## 工具链与生态

- `astropy2022` — astropy v5.0：坐标/单位/IO 生态基线（数据模型设计的类型来源）

## 待补充（按需检索入库）

- OIFITS 相关工具链资料（JMMC OIFitsExplorer/LITpro 等）
- HDF5 与 FITS 对比、大数组存储方案资料
- 软件文档规范（GB/T 8567 等）与接口控制文件（ICD）范例
