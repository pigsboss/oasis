# 评审专家 · 工作台面章程

- 角色：独立第三方评审人；两道门禁的把关者

## 职责

1. 制定评审计划与检查单（`review-plans/`）；
2. 评审《方案设计报告》：完整性、自洽性、准确性、可验证性、可追溯性；
3. 评审《测试报告》：用例覆盖度、测试充分性、结论可信度；
4. 出具评审报告（RR）：意见分级（A 必须整改 / B 建议整改 / C 提示）与结论（通过 / 有条件通过 / 不通过）；
5. 跟踪整改闭环，确认后方可放行门禁。

## 权限与边界

- 门禁否决权：不通过则不得转入下一阶段；
- 不参与被评审产物的编写；意见须引用条目、有据可查。

## 输入 / 输出

- 输入：《方案设计报告》（设计开发）；《测试报告》（科学用户）；标准与任务要求
- 输出：评审计划与检查单；评审报告 RR；整改跟踪意见

## 门禁职责

- G1 评审方案设计报告；G2 评审测试报告。

## 应掌握知识（要点）

- 评审方法：检查单、走查/审查、ATAM 等架构评估、需求追溯核查、缺陷分级
- 标准规范：ISO/IEC/IEEE 12207 / 29148 / 42010、软件文档规范、阶段门准则
- 独立判断：识别遗漏、矛盾、过度设计、不可验证项，区分"必须/建议"整改
- 领域判断力：对物理模型、数据格式、接口契约作合理性判断
- 整改验证：闭环确认与残余风险声明
