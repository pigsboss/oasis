## 三、HDF5 rendition（可选格式）

两份 renditions 均为**单文件、单数据集**结构，便于检索与区间切片：

- 数据集名 **`/table`**（复合 compound 数据集）；文件属性：`columns`、`types`、`rows`、
  `source`、`source_sha256`、`generated_by`；
- 存储：按 65536 行分块 + gzip(6)；**定宽 UTF-8 字节串**存字符串列（避免 vlen 开销）；
  数值列 `int64` / `float64`（缺测 = `NaN`）；
- **字节级可复现**：`track_times=False`，同源重跑 sha256 一致（实测）；
- 读法（含区间切片示例，实测于 T3）：

  ```python
  import h5py, numpy as np
  with h5py.File("gaia/t3/gaia_t3.h5") as f:
      ds = f["table"]                       # 按 source_id 升序
      sid = ds["source_id"][:]              # 3.09M 行整列读取 ≈ 1.0 s
      lo, hi = np.searchsorted(sid, 4.0e18), np.searchsorted(sid, 4.001e18)
      block = ds[lo:hi]                     # 区间切片 ≈ 20 ms
  ```
